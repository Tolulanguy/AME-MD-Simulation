# Molecular Dynamics (MD) Simulation of TLR4/MD-2 Complex with $\beta$-Sesquiphellandrene

This repository contains the code for our project on a multi-scale Systems Neuropharmacology framework integrating molecular dynamics simulations with unsupervised machine learning modeling to elucidate the neuroprotective mechanism of _Aframomum melegueta_.

## Overview

This repository contains the source code and computational models associated with our study on the interaction between **$\beta$-Sesquiphellandrene** (a bioactive compound from *Aframomum melegueta*) and TLR4/MD-2 signaling in the context of LPS-induced neuroinflammation.


## Quick Start

The core computational pipeline and figure generation scripts are available as a Jupyter Notebook. You can run the analysis pipeline directly in your browser by downloading and opening the ipynb file on Google Colab
